FAQ

常见问题

需要 AI API Key 吗？

不需要。MiniLab 内置 mock 模型提供商，全程离线即可完整试用并跑通全部演示。想接入真实模型时，只需在实验室里配置一个 OpenAI 兼容端点。

数据会丢吗？

所有数据都存本地 data/minilab.db（SQLite），进程重启、关机都不会丢。删除该文件即清空实验室，随时可重来。

能在服务器上跑，给多人用吗？

可以。MiniLab 是标准 HTTP 服务，部署到任意 Node.js 主机即可；当前身份认证为 X-User-Id 占位实现，正式鉴权将在后续版本提供。

目前实现到哪一版规格？

SPEC-001～SPEC-010 全部交付，共 356 项自动化测试通过，含一份覆盖全部规格的端到端演示。规格驱动的开发仍在继续，下一个版本会在新规格就绪后发布。

Windows 桌面版、npx、源码版有什么区别？

跑的都是同一份 MiniLab，只是获取方式不同。桌面版 (exe) 内置了 Node.js 运行时和 SQLite，下载后双击即用，适合不想装任何环境的用户；npx minilab 适合已装好 Node.js 的用户；下载源码适合自己改代码、二次开发。

npx minilab 和下载源码有什么区别？

跑的是同一份 MiniLab。区别只在获取方式：npx minilab 让 npm 自动下载并运行最新版，免去克隆和手动装依赖，最适合快速试用；下载源码则方便自己改代码、二次开发。

怎么升级到最新版？

npx minilab 每次都会运行最新版，无需操作；如果全局安装过，运行 npm install -g minilab@latest 即可升级。
